# Receipt font

`NotoSansSinhala.ttf` is the unmodified Noto Sans Sinhala variable font from Google Fonts:

https://github.com/google/fonts/tree/main/ofl/notosanssinhala

Source file: `NotoSansSinhala[wdth,wght].ttf`, downloaded 2026-10-17.

The bundled `NotoSansSinhala-OFL.txt` contains its SIL Open Font License and copyright notices. The font and license are copied into `dist-electron/assets` and included in packaged apps. Chromium shapes Sinhala before ESC/POS rasterization; the printer does not need a Sinhala text code page.
